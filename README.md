# Revision-Assistant-AI
 An AI-powered web application that helps students revise smarter.   Upload notes or past papers → get instant  - summaries, auto-generated quizzes, and a spaced repetition schedule

 # Features
- Upload notes (PDF/text)  
- Smart summaries using NLP  
- Auto-generated quizzes (multiple choice, flashcards)  
- Spaced repetition system (like Anki, but built-in)  
- Progress tracking (stretch goal)  

# Tech Stack
**Frontend:** React (Netlify/Vercel deployment)  
**Backend:** Python (Flask / FastAPI), NLP with spaCy/NLTK/HuggingFace  
**Database:** SQLite (local) → upgradeable to PostgreSQL/Firebase  
**Hosting:** Free tier (Render/Heroku + Netlify/Vercel)
